# Roles

Each page is the commands that suit that person, with examples. The longer
reasoning is in [the journeys](../JOURNEYS.md). The design of `role`,
`pm me`, and the two help pages is in [the plan](../ROLE_REPORTS_PLAN.md).

| Role | Page |
|---|---|
| Product manager | [product-manager.md](product-manager.md) |
| Leadership | [leadership.md](leadership.md) |
| Partner | [partner.md](partner.md) |
| Business analyst | [analyst.md](analyst.md) |
| Developer | [developer.md](developer.md) |
| Service designer | [service-designer.md](service-designer.md) |

The examples on these pages are commands you can run. `role` in the
settings file chooses the report. `pm`, `pm help`, and `pm help roles`
show the commands for that role. `pm <command> -h` shows how to run it.
`pm me` is your own open work.
